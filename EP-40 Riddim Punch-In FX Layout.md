Community-Mapped Punch-In FX Layout

| Pad | Effect Name / Behavior | Pressure / Velocity Function |
| ----- | ----- | ----- |
| **1** | **Beat Repeat / Stutter** | **Division speed / loop subdivision** (varies beat repeat subdivision finer/faster as pressure increases) |
| **2** | **Tape Stop / Slow Down** | **Deceleration rate** (deeper press causes a heavier, slower pitch plunge) |
| **3** | **Filter LFO / Auto-Pan Tremolo** | **Modulation rate / LFO speed** (sweeps faster across the stereo field or cutoffs) |
| **4** | **Low-Pass Filter (LPF)** | **Cutoff frequency** (higher pressure cuts deeper into higher frequencies) |
| **5** | **High-Pass Filter (HPF)** | **Cutoff frequency** (higher pressure cuts deeper into low/bass frequencies) |
| **6** | **Master FX Send Direct** | **Send depth** (punches in full wet-signal burst of your assigned master effect) |
| **7** | **Tremolo / Volume Slicer** | **Chop/Stutter speed** (adjusts amplitude stutter and slice rate) |
| **8** | **Pitch Shifter / Octave Drop** | **Pitch transposition amount / octave blend** |
| **9** | **Bitcrusher / Decimator** | **Sample-rate and bit reduction depth** (harder press creates dirtier lo-fi crunch) |
| **0** | **Sample Remap / Scramble** | **Randomization intensity** (remaps drum/group slots randomly on the fly) |
| **.** *(Dot)* | **Pitch Randomizer** | **Randomized pitch-bend depth** |
| **Enter** | **Granulizer / Input Doubler** | **Grain window size and trigger density** |

Stutter & Looping Mechanics

* **Pad 1 (Beat Repeat) vs. Pad 7 (Tremolo Slicer)**: What you are hearing as a "stutter" is triggered primarily on **Pad 1** (which catches a buffer segment of audio and loops it in divisions like 1/8, 1/16, 1/32 based on pad force) and **Pad 7** (which acts as a hard amplitude/gating stutter). \[[1](https://www.soundtech.co.uk/musicians-blog/our-guide-ep133-koii-sampler-composer-teenage-engineering.html), [2](https://www.reddit.com/r/teenageengineering/comments/1aewm4p/ko2_what_are_the_punch_in_effects/), [3](https://www.soundonsound.com/reviews/teenage-engineering-ep-133-ko-ii)\]  
* **Multi-Pad Layering**: Because the engine processes polyphonic aftertouch across the grid, pressing **Pad 1** (stutter) while pinching **Pad 4** (LPF) will repeat the slice while sweeping the frequency darker simultaneously. \[[1](https://www.soundtech.co.uk/musicians-blog/our-guide-ep133-koii-sampler-composer-teenage-engineering.html)\]  
* **Hands-Free Latching**: While holding FX and pressing any performance pad, releasing the FX button *while still holding the pad* locks the punch-in effect so you can use your free hand on other controls. \[[1](https://www.elektronauts.com/t/ep-133-tips-and-tricks/204124), [2](https://www.elektronauts.com/t/teenage-engineering-ep-series-the-user-thread/241459?page=10)\]
